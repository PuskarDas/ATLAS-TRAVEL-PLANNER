# Dataset Notes

This project ships with a synthetic starter dataset generated by `ml_training/scripts/preprocess.py`.
It is intended for classroom/demo training runs and can be replaced with Kaggle, OpenTripMap,
hotel review, or historical trip preference data.

Recommended columns for real data:

- `destination`
- `budget`
- `duration_days`
- `group_size`
- `interest_beach`
- `interest_culture`
- `interest_food`
- `interest_adventure`
- `rating`
